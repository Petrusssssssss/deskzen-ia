# **App Name**: Coach 5S

## Core Features:

- Dashboard de Auditoria: Página inicial para visualizar o status do Coach 5S, o nível de disciplina e iniciar novas auditorias.
- Captura de Imagem 5S: Permite aos usuários carregar ou capturar (via webcam) imagens de 'antes' e 'depois' para documentar as auditorias 5S, focando em Seiri e Seiton.
- Geração de Feedback do Coach: Utiliza uma ferramenta de IA para gerar dinamicamente mensagens ríspidas e motivacionais do 'Coach 5S', adaptadas ao progresso e ao 'Nível de Disciplina' do usuário.
- Exibição do Nível de Disciplina: Mostra o nível atual de disciplina do usuário na página principal, servindo como um elemento de gamificação para incentivar a melhoria contínua.
- Registro e Salvamento de Auditoria: Funcionalidade para criar, detalhar e persistir dados das auditorias 5S, incluindo imagens e notas, preparado para conexão com o Cloud Firestore.

## Style Guidelines:

- Um esquema de cores claro e focado em ordem, com um tom vibrante e autoritário como cor primária. Primária (tom de púrpura profundo): #692E9A.
- Cor de fundo (cinza arroxeado muito claro): #F6F4F9, para manter uma estética limpa e profissional, contrastando bem com o texto escuro.
- Cor de destaque (violeta-azul vibrante): #7F7FFF, usada para CTAs e elementos interativos, para simbolizar dinamismo e progresso.
- Fontes de títulos: 'Space Grotesk' (sans-serif), para um toque moderno e técnico, evocando a precisão da auditoria 5S.
- Fontes de corpo de texto: 'Inter' (sans-serif), para alta legibilidade em todas as interfaces e um visual neutro e objetivo, complementando os títulos.
- Utilizar ícones simples e consistentes que representem os conceitos do 5S (Seiri, Seiton, Seiso, Seiketsu, Shitsuke), bem como ações de câmera e salvamento.
- Animações sutis e eficientes para transições de tela e ao exibir feedback do Coach, garantindo uma experiência de usuário responsiva e agradável.
